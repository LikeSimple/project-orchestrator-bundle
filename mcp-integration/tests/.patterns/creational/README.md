# 创建型模式

本目录包含 5 种创建型设计模式。

## 模式列表

| 模式 | 说明 |
|------|------|
| [Factory Method (工厂方法)](./factory.md) | 定义一个创建对象的接口，让子类决定实例化哪个类。工厂方法使一个类的实例化延迟到其子类。... |
| [Abstract Factory (抽象工厂)](./abstractFactory.md) | 提供一个创建一系列相关或相互依赖对象的接口，而无需指定它们具体的类。... |
| [Builder (建造者)](./builder.md) | 将一个复杂对象的构建与它的表示分离，使得同样的构建过程可以创建不同的表示。... |
| [Singleton (单例)](./singleton.md) | 保证一个类仅有一个实例，并提供一个访问它的全局访问点。... |
| [Prototype (原型)](./prototype.md) | 用原型实例指定创建对象的种类，并且通过拷贝这些原型创建新的对象。... |

## 使用说明

每个模式文件包含：
- 模式的详细说明
- 适用场景
- 优缺点分析
- 多框架代码示例（TypeScript、React、Vue 3、Node.js）
